# 月间八千代（DeepSeekPet 定制版）

基于 [DeepSeekPet](https://github.com/sjmsltx/deepseek-desktop-pet)（MIT，© 2026 Binyu Li）定制的「月間八千代 / 月見ヤチヨ」Live2D 桌宠。

**本软件为个人定制分享，严禁贩卖。**

## 下载
前往右侧 [Releases](../../releases) 下载最新的 `Yachiyo-portable-v*.zip`，解压完整文件夹后运行 `DeepSeekPet.exe` 即可。

当前最新版：[v1.1.0](../../releases/tag/v1.1.0)

## v1.1.0 亮点
- Live2D 帧率滑块（设置 → 通用，1~60 fps，默认 60），关闭 VSync 后实测约 60fps
- 视线跟随鼠标（支持跨屏幕）
- 思考过程可开关（默认不显示）
- 多显示器、菜单精简、文件夹大小扫描、聊天窗口尺寸记忆

## 使用说明
- 发布包不含 API Key、聊天记录与个人记忆，需自行在程序中配置模型 API
- 联网搜索如需启用请自行配置搜索 Key（如 Tavily）
